# Python: Curso em Vídeo

![Python](https://img.shields.io/badge/Python-3-3776AB?logo=python&logoColor=white)

Meus estudos de Python e lógica de programação seguindo o [Curso em Vídeo](https://www.cursoemvideo.com/), do professor Gustavo Guanabara. Esta foi a base que usei antes de construir sistemas web em produção.

O repositório reúne os exercícios 001 a 015 do Mundo 1 do curso.

## O que pratiquei

- Variáveis e tipos primitivos (`int`, `float`, `str`)
- Entrada de dados com `input()` e conversão de tipos
- Saída de dados com `print()` e f-strings, incluindo formatação de casas decimais
- Operadores aritméticos, incluindo potência para calcular raiz quadrada
- Métodos de verificação de strings, como `isnumeric()`, `isalpha()` e `isupper()`
- Lógica sequencial aplicada a problemas do dia a dia: conversão de unidades e moedas, porcentagens, médias e cálculo de custos

## Organização

Todos os exercícios ficam na raiz do repositório, um por arquivo. O nome segue o padrão `exNNN.py`, em que `NNN` é o número do exercício no curso. Por exemplo, o exercício 7 está em `ex007.py`.

Na maioria dos arquivos, a primeira linha é um comentário com o enunciado.

| Arquivo | Exercício |
| --- | --- |
| `ex001.py` | Variáveis e exibição de dados |
| `ex002.py` | Mensagem de boas-vindas |
| `ex003.py` | Soma de dois números |
| `ex004.py` | Tipo primitivo e informações sobre o valor digitado |
| `ex005.py` | Antecessor e sucessor |
| `ex006.py` | Dobro, triplo e raiz quadrada |
| `ex007.py` | Média de duas notas |
| `ex008.py` | Conversão de metros para centímetros e milímetros |
| `ex009.py` | Tabuada |
| `ex010.py` | Conversão de reais para dólares |
| `ex011.py` | Área de uma parede e litros de tinta |
| `ex012.py` | Preço com 5% de desconto |
| `ex013.py` | Salário com 15% de aumento |
| `ex014.py` | Conversão de Celsius para Fahrenheit |
| `ex015.py` | Preço do aluguel de um carro |

## Como rodar

É preciso ter o [Python 3](https://www.python.org/downloads/) instalado. Depois, clone o repositório e execute o exercício que quiser:

```bash
git clone https://github.com/jhonnalves/python-curso-em-video.git
cd python-curso-em-video
python ex007.py
```

Quase todos os exercícios pedem dados pelo teclado e mostram o resultado no terminal.
